# Vibe Coding — workshop guides

Step-by-step guides for **Chapter 3: Vibe Coding** of AI Foundations
(MIT Sloan 15.S23: AI Builder Space).

**Open them here → https://austinvl.github.io/vibe-coding/**

## This repository *is* the website

Every page you clicked through is a file in this folder:

| file | page |
|---|---|
| `index.html` | the chapter hub |
| `setup.html` | 03 · Set up your machine |
| `warmup.html` | 04 · Build your page |
| `advisor.html` | 05 · Build your MBA advisor |
| `assets/` | the stylesheet, the script, and the images |

GitHub Pages serves this folder as a site: change a file here, and a minute
later the page changes. No framework, no build step — plain HTML, CSS and
JavaScript. Your ticks and your place in each guide are saved in your own
browser only; nothing is sent anywhere.
